# Project Context / 新窗口接续说明

## 一句话定义

LifeSkill Hub 是个人研究与学习控制台：用户用对话发起研究、建立持续关注或学习目标，系统把可靠来源变成可追溯动态和可复习内容。

## 固定边界

- 一级入口只有控制台、世界动态、学习空间。
- Java 21 + Spring Boot 模块化单体负责受控执行；React + TypeScript 负责交互；PostgreSQL 是唯一主库；Flyway 管理迁移；DeepSeek 是推理层。
- Planner、Researcher、Verifier、Composer 是同一 Java Harness 内的职责步骤，不是自治微服务。
- 外部事实先保存 Evidence，Claim 必须引用 Evidence ID，Java Policy Gate 决定是否发布。
- 不展示思维链，只展示已经发生的步骤、工具、来源、状态和耗时。

## 当前可用闭环（2026-08-28）

1. 对话可普通问答、创建并确认持续关注 Skill、发起官方来源研究和生成学习计划。
2. `Java Agent Weekly` 读取 Spring AI 官方 GitHub Release；黄金专题读取 World Gold Council 官方研究。
3. AgentRun 具备状态机、8 步上限、120 秒超时、失败状态、耗时、审计和 SSE 事件。
4. Evidence、Claim、独立 Verifier 与 Policy Gate 已落库；无 Evidence 的结论不能进入动态或学习内容。
5. 动态展示真实摘要、核验状态、来源数量、推荐原因和证据详情，并可生成学习主题。
6. 学习空间按“主题 → 计划 / 知识 / 练习”组织；支持文件夹与用户内容 CRUD、路径进度、阅读完成、随机测验、圈画、反馈和 AI 内容重生成，刷新后恢复。
7. Windows 可在 VS Code 终端运行 `start.cmd` 或 `./start.ps1` 一键启动，并用 `stop.ps1` 停止本仓库服务。

## 当前不可用

- 实时行情、跨来源冲突研判、外部通知。
- 影院官方场次/库存查询、登录、锁座、下单和支付。
- 多模态上传、复习队列、复杂在线富文本编辑器。

上述能力缺少真实 Adapter、权限或 Tool 时必须明确说明不可用，不能伪造成功。购票最终写操作和支付即使未来接入，也必须再次人工确认。

## 当前产品与视觉判断

- 首页不是宣传页，只提供一句问题和少量真实任务入口。
- 双主题使用同一套语义令牌，默认跟随系统并记住用户选择；不再把阅读页固定为浅色。
- 控制台感来自可执行对话、实时步骤、可靠动态和学习联动，不来自虚构地图、数字看板或装饰按钮。
- 长文由安全结构化渲染器显示标题、卡片、表格、代码和友好链接，不直接暴露 Markdown 符号。
- AI 文章/报告正文只读，用户通过反馈、重点和重生成迭代；用户自建笔记、路径和清单可以直接编辑。
