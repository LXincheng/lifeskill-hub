# LifeSkill Hub Design System

## 1. 设计目标

界面应像安静、精确的个人研究工作台：内容密度适中、状态清楚、动作直接。高级感来自排版、对比、节奏和真实反馈，不来自宣传文案、玻璃特效、虚构数据或装饰按钮。

## 2. 双主题与颜色

所有颜色集中在 `frontend/src/styles.css` 的语义令牌，组件只能使用令牌，不按页面自定义一套主题。

| 语义 | 明亮模式 | 暗黑模式 |
| --- | --- | --- |
| 页面 | `#F5F6F8` | `#111216` |
| 表面 | `#FFFFFF` | `#191A20` |
| 正文 | `#202126` | `#F1F1F3` |
| 次要文字 | `#686C76` | `#A4A6AE` |
| 品牌操作 | `#6257CF` | `#9C8CFF` |
| 可信状态 | `#167A5D` | `#61C8A5` |

- 主题默认跟随系统，切换后保存到本地。
- 阅读层也跟随主题，不在暗黑模式中强制显示白纸。
- 状态不能只依赖颜色，必须同时有文字或图标。

## 3. 字体与排版

- UI：Plus Jakarta Sans + Noto Sans SC；代码：JetBrains Mono。
- 正文 15px / 1.75–1.85；元信息 11–13px；页面标题 34–54px；文章节标题 23px。
- 阅读正文最大约 760px，表格与代码最大约 820px。
- URL 渲染为来源名或“域名 · 内容标题”，保留可点击原地址与外链图标。
- Markdown 是存储格式，不是展示格式；标题、列表、表格、引用、代码和图片必须转为安全 React 结构。

## 4. 结构

- 一级入口固定为控制台、世界动态、学习空间。
- 桌面侧栏 236px，中等屏幕 82px，移动端底部导航。
- 首页只保留标题、短说明、任务入口和输入框。
- 学习桌面为主题、文件、正文三栏；手机逐级进入。
- 主题内固定分为计划、知识、练习，文件类型作为元信息而非六个并列目录。
- AI 报告与文章正文只读；批注、反馈、重新生成、阅读状态在正文后的阅读工作台完成。

## 5. 组件与动效

- 只通过 `frontend/src/components/Icon.tsx` 使用 Lucide，主导航 20–21px，常规操作 15–18px。
- 卡片圆角 14–18px，控件 9–12px；胶囊只用于状态。
- 代码块固定深色、提供语言和复制动作；引用显示为克制的提示卡；表格允许横向滚动。
- 动效只用于视图进入、抽屉、状态进度与按压反馈，160–280ms，并尊重 `prefers-reduced-motion`。

## 6. 上线检查

1. 两种主题下正文、次要文字、边框和禁用态是否清楚？
2. 是否存在宣传废话、假数据、长裸 URL、原始 Markdown 或无功能入口？
3. 页面是否只使用统一字体、Lucide 和语义令牌？
4. Agent 是否只展示真实步骤、来源、状态和耗时？
5. 桌面与手机的主要动作是否都可找到并可恢复？
