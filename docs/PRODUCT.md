# 产品说明

## 1. 产品目标

让个人用户用一句自然语言启动可靠研究、长期关注和结构化学习。产品不是新闻门户、任务清单或聊天皮肤，而是把“提出目标 → 受控执行 → 核验结果 → 持续学习”连成一个工作台。

## 2. 三个入口

### 控制台

默认首页。用户可以提问、创建 Skill、发起已接入的研究或学习计划。持续任务必须先显示结构化草案并确认；运行中以流式事件展示职责、工具、来源、状态和耗时。历史对话可切换和删除。

### 世界动态

只展示通过 Policy Gate 的真实内容。每条动态包含摘要、用户兴趣产生的分类、核验状态、来源数量、推荐原因和证据入口。频道来自用户 Skill 与兴趣，不写死金融或 GitHub。

### 学习空间

一个长期目标对应一个“主题”，主题内只有三组：

- 计划：学习路径、行动清单。
- 知识：研究报告、文章、个人笔记。
- 练习：测验，后续扩展代码实践与复习卡片。

文件夹和用户自建内容支持创建、查看、修改、删除。AI 文章与核验报告正文保持只读，避免人工改写后继续伪装成原核验结论；用户可以圈画、提交修改建议并请求 Agent 生成新版本。学习进度、测验与批注刷新后恢复。

## 3. 可信规则

- Evidence 保存来源、URL、发布时间、采集时间、原文和内容哈希。
- Claim 必须引用已保存的 Evidence ID。
- Verifier 使用独立上下文核对结论；Java Policy Gate 再做确定性发布判断。
- 低置信、来源失效或无 Evidence 的内容不能进入动态或可靠学习内容。
- AI 根据个人目标生成但没有外部证据的学习内容标记为 `AI_GENERATED`，不能显示成“已核验”。

## 4. 能力边界

- 当前官方来源：Spring AI GitHub Releases、World Gold Council 官方研究。
- 实时行情必须接入带报价时间和原始响应的可靠 Adapter，数字由代码重算，模型只解释。
- 购票分为只读场次/库存 Adapter 与写操作 Tool。登录、锁座、下单、支付必须明确授权并在最终动作前确认。
- 外部通知是独立写操作 Tool；发布动态不代表通知已发送。

## 5. 体验原则

- 页面干净、紧凑、可读，支持明亮/暗黑模式并保持同等对比度。
- 不使用宣传口号、虚构用户名、假数据、无功能按钮和大面积装饰。
- 链接显示来源名称或易读文本，不把长 URL 当正文。
- Agent 协作展示可验证流程，不展示或伪造思维链。

## 6. 当前成功标准

- 用户能从聊天创建并确认 Skill，手动运行或暂停/恢复。
- 运行能调用真实官方来源并生成可追溯 Evidence 与 Claim。
- 通过核验的内容能进入动态并一键生成学习主题。
- 用户能完成路径、阅读和测验，给 AI 内容反馈并得到新版本。
